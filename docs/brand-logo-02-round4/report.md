## F-1の素材・SVG化

素材は今回提供の白背景・黒いシンボル画像`1-写真1.jpg`のみ。他のロゴ、過去案、耳などの具体的モチーフを追加素材として使用しない。

素材SHA-256: `373e88dba8c639f3f329761f2bb59c7efa4985b583fd6f4306028d9e22a84651`。

RGB平均輝度128で黒いシンボルと白背景を分離し、marching squaresで外周・内側への折り返しを含む輪郭を抽出。主要な2つの閉輪郭をそのまま保持する。1pxの孤立断片のみ除外。0.18元画像px以内のポリゴン簡略化と小数3桁への丸め、原点への平行移動を行い、evenoddの塗りつぶしパスへ変換した。一定幅stroke化、膨張/収縮、中心線からの再設計、回転、端部補正、線幅調整は行わない。

抽出範囲: x279.375–929.281、y286.561–972.454。viewBox `0 0 649.906 685.893`。472頂点、1 path内に2輪郭。原案と同じ主要2領域・曲線の太さの変化・中心の空白・曲線間の空白・外側端部を維持する。

原案二値輪郭に対する簡略化後マスクのIoUは99.83%。差異は輝度閾値、輪郭簡略化、座標丸め、除外した1px断片に由来する。JPEGの濃淡/アンチエイリアスを完全再現する正式SVG原本とは扱わない。黒は#f0f1f3単色へ反転し、白背景や画像内の淡い紙面模様は持ち込まない。SVGに格子模様・外部参照・script・イベント・メタデータはない。装飾としてaria-hidden=true、focusable=false。

原案の主要2輪郭間の最小距離は約26.08元画像px（40px高で約1.52px相当）。抽出後も領域の結合はなく、中心部と曲線間の空白を保つ。数値は原案マスクでの計測であり、実機でのアンチエイリアスの見え方は別途評価する。
