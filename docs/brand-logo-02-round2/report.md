## 操作

https://deploy-preview.my-listening-archive.pages.dev/?logo-compare=1

右下の一時パネル「Logo」の **C-1 / B / E** をタップする。パネルは既存下部ツールバーの上に固定され、アーカイブ・統計・ページ中段でも操作できる。操作領域は各44×44px以上、選択状態はaria-pressedで通知。Tab・Space/Enterにも対応。

選択時に変更するのはシンボル配置領域の専用data属性（CSSで表示切替）と比較ボタンのaria-pressedのみ。C-1の既存SVG文字列は一切変更しない。h1・page-heading・tabindexも維持。再読み込みするとC-1へ戻り、選択状態は保存しない。URL指定がない通常表示ではパネルなし・C-1表示。

一時パネルは検証用オーバーレイのため、その直下の画面内容を覆うことがある。比較を終えたらクエリを外して再表示する。正式選定時は`brand-compare.js`、その参照・許可リスト項目、一時パネルCSS、未採用シンボルを撤去する。

## SVG化と形状差

素材は今回運営者提供のB/D/E/I/K比較JPEG（`1-写真1.jpg`）だけ。D/I/Kは不使用。素材SHA-256: `c6fb606ca917f1291e6a8b53fc22b0e3bb97d62c10ae5fa97a9fe95ea0a5f2ae`。既存C-1は前回SVGをそのまま保持し、回帰試験で以前のコミットから取り出した文字列と一致を確認。

Bは元画像x215–355/y125–287、Eはx210–363/y580–720を切り出し。RGB平均輝度の等高線をmarching squaresで抽出。外周だけでなく内側の輪郭も保持し、fill-rule=evenoddの白系単色パスへ変換。一定幅strokeや新たな造形への置換はしない。

Bの側面・背面の細い線は原案で灰色に薄く描かれているため、輝度65の低い閾値を採用。Eは128。0.8px²以下のJPEG由来の極小断片のみ除き、0.12元画像pxの許容値で輪郭簡略化。原点移動と小数3桁の丸め以外に手調整なし。

Bの細い側面や背面を失わないことを優先した結果、低閾値でアンチエイリアス部分も輪郭へ含まれ、明るい境界は高い閾値の場合よりわずかに太くなる。65未満へフェードする末端は抽出限界がある。原案の明暗濃淡は白系単色へ統一。Eの交差・線幅変化・楕円の空白は抽出輪郭で維持する。両案ともラスター画像からの近似であり、正式SVG原本との完全一致とは扱わない。ヘッダー縮小時の細線の見え方はSafari実機で評価する。

## 共通条件と文字拡大

- 全3案・全検証幅でシンボル高さ40px。デスクトップも40pxへ統一。
- 共通配置領域42×40px、各シンボルを中央配置。固有の縦横比を維持し、文字開始位置は切り替え前後で不変。
- Josefin Sans 2.001、Regular 400、字間.02em、行高1.25、色#f0f1f3、既存#11151b背景。フォント・OFLファイルは変更なし、ローカル配布。
- 間隔10px（540px以下）/12px（それ以外）、ブランド上5px・下16pxを3案で共通化。
- 文字サイズ: 320pxで24px、375pxで約27.01px、390pxで約27.84px、393pxで28px、430/1280pxでも28px。
- 393pxの旧約22.65pxから28pxへ拡大。通常時は1行、拡大文字設定では折り返して欠落を防ぐ。
