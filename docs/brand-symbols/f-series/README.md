## 思想

F系は、螺旋階段の内側にいる当事者が上方または下方を見る視点を表す。時間の中にいる自分には、進んでいるのか戻っているのか、どこへ向かうのか分からなくなることがある。経験の積み重なりや変化は、記録して振り返ることで初めて軌跡として見える。

抽象的な曲線は結果として耳にも見え、音楽を聴く主体としての自分自身を重視するMLAの思想と調和する。具体的な耳・音符・レコード等を追加した造形ではない。

アプリのヘッダー表示とブランドシンボルの造形は分けて検討する。第6次では日常的なアプリのヘッダーをロゴタイプだけにして比較する一方、F系は今後のXプロフィール等への展開候補として保存する。
