## 実装結果

`commitDB()` / `saveDB()` / `saveRecord()` を非同期化。DB保存キーへの書き込みは `commitDB()` 内の1箇所のみ。Listening・Collection・Liveの登録/編集/削除、写真変更/削除、JSON復元、旧キー起動時移行がこの経路を利用する。UI言語キーはDB保存とは独立。

共通ロック名 `mla:my-music-archive-pilot-v03:write`、`navigator.locks.request(name, {mode:'exclusive', ifAvailable:true}, ...)` を使用。候補をPR-A検証で独立したスナップショットにしてから要求し、ロック内で読込失敗状態、現在raw、基準raw、操作対象の内部IDと元オブジェクト、候補全体を再検証する。現在rawは毎回ロック内で読み、null/空文字を区別して厳密比較。成功後にだけメモリDBとbaseRawを更新する。失敗時の書き戻し・マージ・上書き選択肢はない。

非Secure Context、API不在、取得不能、要求拒否/例外、raw不一致、storage通知による変更検出、整合性異常、ストレージ例外で停止。保護を弱めた方式へ降格しない。storageイベントは補助通知のみ。通知なしの同一ページ側変更・削除・空文字でもraw照合が拒否する。

ロック中に写真変換・ファイル読み取り・確認ダイアログ・通信は行わない。これらは操作ガードの範囲内で先に実施。入力コントロールとナビゲーション/カスタム操作のイベントを制御し、二重送信を拒否する。削除確認と写真変換の前後で対象を維持・再確認する。フォームの閉鎖・初期化・完了表示はawait成功後のみ。

旧キー移行も同じロックを使用。現行キーがnullのままであることと旧キーraw不変を検査し、PR-A検証後に現行キーへ書く。中断時は旧キーを変更/削除せず、書込停止と原本回収を表示。再読み込みで安全に再試行する。

## 未保存入力の回収

失敗時はフォームと元のFile選択を維持し、フォーム内に回収パネルを表示する。専用JSONの識別子は `format: "mla-unsaved-input"` / `formatVersion: 1`。通常のDB形式ではなく、通常の復元で拒否される。

含む内容: 領域、操作種別、内部記録ID、現在フォーム値（部分入力の日付部品・出演者名も含む）、最後に保存を試みた対象レコードと処理済み写真、失敗理由、キーの存在情報、選択写真の名前/型/サイズ。DB全体・baseRaw・無関係な領域の入力は含まない。削除は対象IDと説明用入力のみで、実行用パッチや候補DBを出さない。JSON復元失敗では元バックアップを保持するよう案内し、アーカイブ全体を回収ファイルに複製しない。

写真原本のバイナリは埋め込まず、保持が必要な旨を明示。処理済み写真は取得済みなら対象レコードに含める。ダウンロードに失敗しても全JSONをreadonlyテキストから選択・コピーできる。ダウンロードクリックだけを回収成功とは見なさず、利用者が保存先/コピーを確認して「回収内容を確認済み」を押すまでフォームを閉じる/切り替える操作を止める。確認後も自動でフォームを破棄しない。部分的な写真削除が成功しても、失敗した編集の回収状態を消さない。再読み込み/離脱にはbeforeunloadを補助的に使用する。

PR-Aの全体拒否、未知プロパティ保持、旧形式互換性、内部ID一意性・曖昧操作停止、成功後DB確定、DP-01/02/06の原本回収・失敗時既存値保持を維持。DB version・キー・通常バックアップ形式は変更していない。

## 残存リスク・③への引き継ぎ

- 保証は同一保存領域で共通ロックを使う協調タブ間に限る。旧版タブ・拡張機能・外部スクリプトがロックを無視して照合後から書込までに変更する場合は完全防止できない。同一rawへ変更して戻す履歴もraw比較だけでは識別しない。
- 非対応環境は閲覧/バックアップ/入力回収を維持して保存を拒否する。実際のブラウザ保存可否はSecure ContextとWeb Locks提供状態に依存する。
- 競合時は回収して再読み込みする。自動マージ・ドラフト自動復元は提供しない。
- 写真原本の自動書き出しはしない。大きい処理済み画像を含む回収JSONのコピー/保存は端末容量の影響を受ける。ダウンロードAPIはOSへの保存完了を検知できないため利用者確認が必要。
- 強制終了・OSのページ破棄後の未保存入力保持は保証外。beforeunloadもブラウザ次第で発火しない。
- 実容量不足は例外注入のみ。iPhone Safari実機は未検証。

③では少数の合成記録だけで、iPhone SafariのWeb Locks、2タブ保存/バックグラウンド復帰、ロック中断・再試行、回収JSONのFilesへの保存と内容確認、写真付き回収、実容量不足、凍結/復帰を確認する。大量登録やコンソール操作は不要。自動試験の成功でこれらを実機合格としない。
