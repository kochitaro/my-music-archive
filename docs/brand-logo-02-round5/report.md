## 線幅調整方法・暫定判断

F-1の塗りつぶし多角形をSVG座標で3倍サンプリングし、medial axisと距離変換から中心線と局所半幅rを推定する。内側への距離dが概ね`d >= (1 - 目標倍率) × r`となる領域を抽出し、90%/80%へ細くした。各側を局所半幅の10%/20%ずつ内側へ移す方式で、一定量の収縮やSVG全体の縮小ではない。局所半幅の推定値だけを0.5 SVG座標単位相当で平滑化し、格子の小さな揺れを抑える。

4端部の中心座標(603,98)、(496,684)、(241,455)、(312,472)について、半径16単位内は変位量を0にし、16〜48単位で滑らかに通常の変位へ移行する。斜めの外側切断面と細い先端を優先し、厳密な比例より形状維持を優先した。端部近傍の輪郭を双方向比較した最大差は約0.281 SVG座標単位（40px表示で約0.016px）。差は主にサンプリングと輪郭簡略化によるもの。

生成輪郭は0.20 SVG座標単位以内で簡略化し、小数3桁へ丸める。F-2は559頂点、F-3は507頂点。全案で主要な2連結成分を維持し、細線の断裂や2曲線の結合はない。F系のviewBoxは全案`0 0 649.906 685.893`で共通。個別フィットや縦横別の拡縮はせず、F-2/F-3では線幅を内側へ動かした結果だけ外接寸法が変わる。

線幅比率は目標値。局所半幅の推定・端部固定・曲率の影響があり、全点で厳密な90%/80%を保証しない。形状の維持を優先した近似調整である。
