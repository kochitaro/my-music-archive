## 線幅の調整方法

全体の拡大縮小は行わない。原案マスクのmedial axisと距離変換から、各位置の中心と局所半幅rを推定した。輪郭から内外への符号付き距離dに対し、概ね`d >= (1 - 倍率) × r`となる領域を採用する。80%では左右それぞれ局所半幅の20%を内側へ、120%では20%を外側へ動かす考え方。一定量の膨張・収縮と異なり、太い手前と細い奥の強弱を維持する。

局所半幅の推定値だけを0.25元画像px相当で平滑化し、距離場の小さな揺れを抑制した。4端部（元画像座標180/115、164/239、167/201、164/324）は半径2px内の変位を0にし、2〜6pxで滑らかに通常の変位へ移行する。端部の切り方・先端を維持するため、そこでの線幅は厳密な倍率にはしない。B-3は距離場ではなく元の輝度等高線を使うため、他案との格子境界にも最大約1/8元画像px単位の微差がある。

これは塗りつぶし形状の**視覚的な近似線幅**。各点の幅が厳密に80〜120%になることは保証しない。以下の独立した面積・断面・連結性計測で、大きさの変更ではなく線幅の強弱が段階的に変わることを確認した。

断面と距離は元画像px換算。断面は共通座標x=54でSVG多角形との交点から独立計算した垂直断面であり、線に直角な厳密ストローク幅ではない。下側リボンの断面も`trace.json`に記録。5案とも連結成分は2つを維持し、細線の断裂や上下リボンの結合なし。B-5の最小距離はヘッダー上で約2.04px相当。

全案同じviewBox `0 0 137.863 211.133`を使う。最大線幅案まで含む横幅の共通枠で、各案を個別にフィットし直さない。上下端の画素範囲は5案で一致。線幅の変化に伴う横方向の輪郭移動はあるが、図形全体の拡大縮小・縦横の引き伸ばしはない。

SVGは1個のpath内に2輪郭を保持。外部参照・script・イベント・メタデータなし。aria-hidden=true、focusable=falseを維持。元画像や比較資料、作業用生成スクリプトはdistに含めない。
