横棒は`#89BCCD`単色のまま。鑑賞/購入時期の月別・年別、リリース年別の1行構成・年月のnowrap・期間下限・0件維持・追加表示を変更しない。

色は表示上の順位から決めず、月は絶対年月番号（年×12＋月−1）、年は西暦年、年代は年÷10の整数を15で循環させる。同じYYYY-MM・年・年代はスクロール・ジャンプ・表示範囲変更でも同色。隣接する月/年/年代は別色で、5年・10年を同色のグループにはしない。その他の円の色は`#414951`を維持。

## Live月別：連続スクロールと描画方式

最古の有効な年月から現在月までの全期間を古い順に配置。記録開始前・未来月は作らず、期間途中の0件は保持する。年切替方式を廃止し、グラフ領域内だけの横スクロールとした。ページ全体は横に広がらない。

初期は最新月を右端にした直近最大12ヶ月。12ヶ月未満は存在する期間だけを描く。月と年を分けて表示し、上に可視期間のYYYY-MM範囲を表示。4桁の年ラベルは可視月の同一年グループの下へ置き、端で切れないよう調整した。端数ピクセルのせいで初期範囲が13ヶ月になることも防いだ。

縦軸は左側の独立SVGで固定。全期間の最大件数から一つのスケールを決定し、横移動や年ジャンプでは変更しない。

**仮想描画**：集計と全月データは保持するが、横長SVGに全棒を作らない。全期間の幅を持つ空のスペーサーに、画面内＋左右2ヶ月程度だけのSVGを絶対配置する。スクロールはrequestAnimationFrameでまとめる。実測の最大描画棒数は17本だった。年数が増えても画面付近のDOM数は増えず、SVG/Canvasの極端な横幅制限も避ける。ResizeObserverで画面幅変更時の月位置を保持し、再描画・項目切替時に監視を解除する。

年ジャンプは全期間の年から選択し、指定年の1月を左端の基準位置にする。最古年の開始月より前なら開始月に、末尾で1画面分を取れない場合は末尾にクランプする。これは年による絞り込みではなく、連続グラフ内の位置移動。左右キーは1ヶ月、PageUp/PageDownは12ヶ月、Home/Endは最初/最新へ移動。読み上げ用の名称と画面付近の年月・件数を持つ。

年精度のみ/日付不明の記録を月別に入れない既存ルールは維持。年精度のみの過去記録を便宜的に1月へ割り当てない。月別対象がなければ空状態、年別には有効年を含める。

## Liveスコアランキング

補足で確定した仕様を採用。公演年の選択や集計方式切替は**設けず**、日付不明を含む全期間のスコア設定済み公演を対象とする。未評価は除外、0.0は含める。既存の5点換算スコアの降順・同点同順位（1,1,3方式）・同点の元配列順を維持し、記録単位、初期15件・15件ずつ追加。白系単色。

順位｜写真/代替表示｜公演情報｜スコア。写真があれば既存表示を使用し、なければ既存の音符。Liveで写真がないためにCAAへアクセスすることはない。主表示は公演名・フェス名で、その場合出演者名は出さない。公演日と会場を補助表示。長い主表示・補助情報は2行を基本とする。

公演名がない場合の描画分岐では、出演者を登録順に` / `で連結して代替表示する。重複排除・並べ替えはしない。

**既存仕様との差**：調査した現行Live検証は公演名を必須としており、空白名の保存/JSON復元を拒否する。これは作業中に報告済み。保存安全性の指示に従い、この検証は変更していない。出演者名への代替は描画側の防御として実装し、保存を通さない描画単体で確認した。現在の通常データで公演名なしを新規作成できるようにしたものではない。

初期はアーティスト直下。保存済みLive設定は既存順序・表示状態を保持し、新しい`score`を末尾に表示状態で追加。設定未保存と初期化時はアーティスト直下。保存方式は第2次と同じ独立localStorageキーで、記録/写真/既存settings/metaを再保存しない。
